# 仓库介绍与对外文案

项目名称：**点击语境查词** / **Click Context**

公开仓库：[a1986884/click-context](https://github.com/a1986884/click-context)。

## About（可直接复制）

点击英文单词，结合原句查看此处含义。支持划词翻译、Collins 词典对照、原句生词收藏与网页双语阅读；点击语境、正文和选文可分别选择引擎，支持自带 API。

英文简介：Click a word to understand its meaning in context. An open-source browser extension and userscript with dictionary lookup, independently selected AI/translation APIs, saved sentences and bilingual reading.

## 简短发布介绍

**读英文网页，不懂的词，点一下。**

点击语境查词会结合你所点的单词和当前原句，解释它在这里的意思。Collins 词典原义与 AI 语境释义分开标识，便于对照；还可以把词义连同原句收藏。需要时，开启选文翻译或逐句 / 逐段双语阅读。

当前是持续验证中的开源扩展候选，模型释义仍可能出错；原生安装与新增付费 API 的验收状态需要看具体版本报告。

## 介绍顺序

先展示“点击单词 → 看原句中的含义 → 收藏这次用法”，再介绍划词和双语阅读。保持功能描述具体；不使用“行业首创”“唯一”“零误差”“全模型可用”等未经验证的表述。
