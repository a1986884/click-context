# 点击语境查词 · UI 设计

主文案：**点一下单词，看懂此处词义。**

## 信息顺序

- 首页：一句话说明用途，bank 两种语境的明确标记示意，进入可点击的真实阅读区域。示意不是预录的“实时 AI 结果”。
- 工具栏：当前网页 / 状态 → 点击查词主开关 → 辅助阅读 → 生词本与引擎设置 → 网站与隐私。
- 词卡：所点单词 / 来源 → 当前原句 + 释义 + 实际 AI 或失败状态 → 其他义项与词典解释 → 收藏 / 朗读。原句从折叠详情移到可见区域；长内容可滚动，底部操作不挤出卡片。
- 引擎页：正文、选文两栏独立选择；API 配置集中管理。词卡语境仍按当前真实服务说明，不暗示这里能切换语境引擎。

## 视觉规则

墨绿文字 `#173C38`，功能绿 `#087F6F`，浅灰绿背景 `#F5F7F3`，白色内容卡。绿色用于查词主动作、当前含义及选中词；正文保持清楚的衬线英文与舒展行距。圆角以9/13/16px为主，少量阴影，不用大面积品牌插画占据阅读空间。

桌面首页两栏，窄屏上下排列；控件至少44px触控高度。保留可见键盘焦点、词卡拖动/键盘移动、收起/展开、Escape关闭与减弱动画偏好。扩展工具栏和词卡保留深色模式。

## 兼容边界

用户可见名称改为「点击语境查词」。`lextide-reader`、存储键、缓存、注册ID、部署地址、历史文档及脚本兼容文件名保留，避免更名重置已有设置和生词。没有修改查词/AI模型、权限规则、API密钥存储、正文翻译或原文恢复协议。
