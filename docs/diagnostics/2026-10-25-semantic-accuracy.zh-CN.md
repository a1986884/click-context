# 0.7.145 释义准确度候选：未上线，未宣称完美

本轮只处理释义准确度，服务可靠性暂不排查，暂不上传 GitHub。公开预览仍为 0.7.144，原生包版本 0.7.98 保留。本轮没有 GitHub CI；以下是本地测试及模型接口试验。

## 已实现

v5 独立解释选中的单词或短语，不向生成、复核模型提供词典候选、候选 ID 或词典摘录。只有词根、词性及完整中文义项或顶层别名唯一匹配，才附加词典来源。复核修正或未确认的结果不能强行挂到更窄的 Collins 义项。

初步生成使用 medium 推理、450 输出 token；复核使用 low 推理，可使用首阶段未花完的预算。单次尝试两步实际输出预算仍为 900；原 16 秒期限、最多两次尝试及限流不变。不是保证一次请求最多调用两次模型。v3/v4 的提示词、采样和单次推理行为保持兼容。

两阶段使用同一可视化选词标记和准确位置。复核只有明确确认仍解释选中范围时才能修正。范围未确认就保留初步释义；修正缺少原句引证也标明未确认。未确认状态本身禁止词典来源匹配，即使响应遗漏独立的禁止匹配标志。复核支持原答案时不采用附带的无关改写。未确认说明随收藏保留。

自配 API 仍为单次独立释义；只有四种协议的模拟测试，没有实际自有 API 验收。

## 未采用的尝试

原 v3/v4 均把泛指 station 译为“火车站”；v3 把机械语境 strain 译为“应力（变形程度）”。只加强提示或增加自评字段仍产生过窄释义、错误候选 ID，均保留失败结果，未发布。

独立生成仍会把 terminal 限定成“航站楼”。部分复核能给出多个读法，但新增自报歧义和术语纠正说明又复现过窄解释，因此撤回该提示词扩写。不把模型自报“无歧义”当事实。

加入词典参考、额外范围对照、中文强调、反方歧义提示，都未稳定改善：出现 bass 修饰语变成演奏者、鱼义过于笼统，或过度怀疑课程用法。GLM-4.7-Flash 也出现演奏者错误；Qwen3-30B 未提供有效最终正文并包含错义，均未替换生产模型。测试判定曾漏掉“贝斯手”，现已加入反例，不能靠包含“贝斯”二字算通过。

当前服务列出的 DeepSeek-V4.1-Flash-1017、GLM-5.3-Flash 对照调用，被免费套餐以 5035/HTTP 403 拒绝。该结果不说明账号停用；未重复登录授权，也未开通付费。付费也不能保证零误译。
