# 语境精读 · Closeread 界面规范

副标题：为英语学习者设计的网页精读插件。

## 配色与字体

浅色：页面 #F4F4F0，卡片 #FFFFFF，正文 #1A1A1A，次要文字 #6B6B65，边框 #E2E2DC。
深色：页面 #16161A，卡片 #1E1E22，正文 #F2F2EE，次要文字 #A6A6A0，边框 #34343A，批注底 #26262B。
黄色 #FFE45C 仅用作背景，黄色上的文字为 #1A1A1A。主按钮黑底白字，深色模式反转；链接用墨色加下划线。聚焦轮廓浅色为 3px #1A1A1A，深色为 3px #FFE45C。尊重 prefers-reduced-motion。

## 词卡

顺序为小标题行 → 中文释义与词性 →“语境释义”及来源说明 → 英文解释 → 原句 → 折叠义项/例句来源 → 收藏。中文释义衬线体 34px，窄屏 30px；英文 Georgia；原句次要色、黄色 mark 标记所点词。mark 通过 DOM 节点构造，保留原句 textContent。其他义项显示完整英文。保留现有 role、选择器和存储协议。

## 悬浮书本

46px 圆角方块。关闭为黑底黄线的合上书本；开启为无黑色边框的黄底黑线展开书本。单击暂停/恢复，长按约半秒进入设置，拖动改变位置，Shift+F10 提供键盘入口。
