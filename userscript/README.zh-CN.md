# 语境精读 · Closeread 用户脚本

为英语学习者设计的网页精读插件。当前油猴源码版本为 **0.8.1**，与扩展共用阅读器、词卡、正文翻译和生词本代码。

## 安装与构建

- [公开安装页](https://click-context-install.aa1986884.workers.dev/)：需先安装并启用兼容的脚本管理器。
- 构建当前源码：在项目根目录运行 `npm ci`、`npm run build:userscript`，将 `build/userscript/click-context.user.js` 导入管理器。
- 脚本命名空间、文件名、更新地址及存储键保持兼容，已有收藏和设置无需迁移。

## 操作

首次访问网站时，点击右下角书本启用。长按约半秒进入阅读设置；单击暂停/恢复，拖动调整位置。支持点击单词、划选短语查询、选文翻译、逐段/逐句双语、原文/双语/译文模式、生词收藏、编辑与 JSON 备份。

## 网站设置

长按书本打开阅读设置，展开“网站设置”：

- **记住此网站设置**：保存查词开关、阅读模式与逐段/逐句选择，下次访问该网站时恢复。
- **排除此网站**：停止当前网站的查词和翻译；取消排除后可继续使用。
- **暂停所有网站**：统一暂停已打开页面，保留各网站的功能设置。

收藏和 API 配置由脚本管理器跨网站保存；阅读设置按网站保存。登录、账户和支付页面仍需手动开启。

账号中的聊天会员通常不含 API 额度，真实 API 接入取决于凭据与服务。
