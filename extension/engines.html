我的 API 配置

AI 聊天会员通常不含 API 额度。谷歌、微软和 DeepL 使用各自官方 API；自定义服务按所填地址发送文本，不自动切换其他服务。

Responses 使用完整 /v1/responses 地址，单次文本请求，不建立对话。仅支持该接口的模型请选此服务；模型 ID 仍需在账号中可用。

密钥仅保存在本机扩展中，不同步、不回显，也不随生词本导出。此存储不是硬件加密保险箱。不要把密钥填入地址或配置名称。

浏览器按主机授权，包含该主机的端口。只有使用所选引擎翻译，或主动点击测试，才会发送相应文本。
