语境精读 · Closeread

为英语学习者设计的网页精读插件

读懂单词在原句中的含义。
点击英文单词，结合当前原句查看中文含义与英文释义，展开词典义项核对用法。支持划词翻译、网页双语阅读，并可将这次词义连同原句收藏。

为什么使用语境精读

整页翻译适合快速了解大意。当你想继续读英文原文、弄清某个词在这句话中的具体用法时，语境精读提供词语层面的解释与核对依据。

  • 结合当前原句查义：先看中文，再对照英文解释，减少在多个释义之间来回查找。
  • 保留词典依据：展开其他义项、例句和来源，自行核对 AI 的判断。
  • 按需要获得帮助：可以只查一个词、翻译选中的一段，或开启网页双语阅读。

开始使用

  1. 启用阅读工具：安装后在浏览器工具栏启用当前网页；按需要记住网站设置。
  2. 点击英文单词：查看语境释义、词性、英文解释和原句；展开其他义项可切换词典释义。
  3. 开启双语阅读：长按右下角书本按钮，在阅读设置中开启“正文双语翻译”，选择逐段或逐句对照。
  4. 按需收藏：将词义连同原句保存到生词本，之后搜索、编辑或导出备份。
长按右下角书本约半秒，进入阅读设置。

单击：暂停 / 恢复本页查词与正文翻译。
拖动：调整按钮位置。
键盘：聚焦书本按钮后按 Shift + F10 打开设置。

书本合上表示暂停，展开表示启用。暂停会保留当前功能设置；启用后的查词区域中，英文链接文字优先用于查词，关闭查词后恢复正常跳转。

完整功能

功能可以做什么
单词与短语点击单词或划选短语查询；显示音标、词性，支持单词朗读。词条以实际获取结果为准。
语境释义参考当前原句解释词义；匹配时使用词典义项，未匹配时可显示单独标注的 AI 英文释义。
词典对照展开其他义项、切换词义、查看例句和词条来源；AI 候选保留待核对提示。
划词翻译选中句子或段落，主动点击“翻译选文”，无需先翻译整页。
正文双语阅读逐段英汉对照，或在每个英文句子后显示中文；正文翻译由用户单独开启。
三种显示模式原文、双语、译文模式切换，随时恢复英文原文。
本地生词本保存词义与原句，搜索、排序、筛选待核对词条，编辑释义与核对状态，删除与撤销。
备份与迁移JSON 导入和导出；卸载或更换浏览器前可自行备份。
引擎与自带 API查词与语境 AI、翻译引擎分别设置，正文和选文共用翻译引擎。真实 API 配置需要在插件中完成。
阅读控制词卡拖动、收起和关闭；按钮拖动与位置重置；重试失败翻译、清除翻译缓存；深色外观。

隐私与结果来源

  • 词典查询发送所查词语；语境分析发送当前原句及定位等必要信息。
  • 选文翻译仅发送所选内容；正文翻译开启后，会发送需要翻译的正文至所选服务。
  • 生词和设置保存在浏览器或脚本管理器的本地存储中，没有插件自己的云端生词同步。
  • AI 可能判断错误。AI 生成内容单独标注，不作为词典原文；不确定时请对照原句和来源核对。

开发与贡献

需要 Node.js 22+。下载源码后，在项目目录执行：

npm ci
npm test
npm run check
npm run build

用户脚本构建：npm run build:userscript。欢迎反馈原句提取错误、词义偏差、无法点词的网页或界面问题；请附浏览器版本和不含隐私的复现示例，不要提交 API 密钥。
